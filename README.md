# Daniel Apresian — portfolio

Одностраничный сайт-портфолио. Откройте `index.html` в браузере (нужен интернет для Google Fonts).

## Структура
- `index.html` — готовый сайт, один самодостаточный файл (стили, скрипты, скриншоты и три проекта внутри).
- `assets/screenshots/` — превью работ, которые встроены в `index.html`.
- `projects/` — исходные HTML-файлы трёх работ. Они же встроены в `index.html` (переменная `SITES`) и открываются по клику на карточку (картинку или название). В окне просмотра есть кнопка «Open in new tab» — та же работа отдельной страницей.

Если меняете файл в `projects/`, не забудьте обновить такую же работу в `SITES` внутри `index.html`.

## Что менять
В `index.html` найдите и замените:
- `Daniel Apresian` — имя (заголовок, шапка, подвал, `<title>`);
- `luminavedd@gmail.com` — почта (ссылка, текст и кнопка копирования);
- `facebook.com/profile.php?id=61561815989650` — ссылка на Facebook;
- тексты в разделе About и список услуг.
